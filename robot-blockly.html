主要功能

从积木搭建到真机运行，编辑器、代码生成与设备遥测在同一个桌面应用内完成。

积木编程

基于 Google Blockly，拖拽搭建动作序列，支持循环与条件嵌套。

代码生成

一键生成可读的 Python 代码，直接对接 unitree_sdk2py 接口。

一键运行

在应用内执行生成的脚本，输出实时捕获到日志面板。

实时状态监控

DDS 订阅 rt/lowstate，显示 IMU、电池与电机状态。

摄像头回传

实时显示机器人摄像头画面，用于对位与调试。

激光雷达点云

叠加显示 Go2 激光雷达点云，支持测距标尺。

程序存取

Blockly XML 工程文件保存、加载，并可导出为 .py。

跨平台支持

支持 Intel（x86_64）与 Apple Silicon M 系列（arm64）芯片，以及 Linux x64。两种 Mac 架构安装包互不通用。

快速开始

两种方式上手：直接使用打包好的安装包，或从源码运行以便修改积木定义。

方式一：安装包安装

macOS (Intel) 下载 .dmg，Linux 下载 .deb，请前往上方下载中心选择对应平台。

方式二：从源码运行（需 Python 3.10 与 conda 环境）

# 1. 创建 conda 环境
conda create -n unitree python=3.10 -y
conda activate unitree

# 2. 安装依赖
cd blockly_unitree
pip install -r requirements.txt

# 3. 获取宇树官方 SDK（第三方组件）
git clone https://github.com/unitreerobotics/unitree_sdk2_python.git ../unitree_sdk2_python
pip install -e ../unitree_sdk2_python

# 4. 启动
python -m app.main

网络配置

有线直连 Go2 时需手动配置静态 IP，机器人出厂不提供 DHCP。

Go2 出厂固定 IP 为 192.168.123.161，不提供 DHCP。需将电脑网卡通配静态 IP 192.168.123.241/24：

# Linux
sudo ip addr add 192.168.123.241/24 dev <网卡名>

# macOS
sudo ifconfig <网卡名> 192.168.123.241 netmask 255.255.255.0

软件内置网卡检测与一键配置（Linux），选择正确的有线网口即可。

固件要求

  • Go2 固件 ≥ 1.1.6（MCF 模式）
  • 运动控制需先调用 BalanceStand() 解锁，再发送 Move 指令
