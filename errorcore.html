Robot Blockly

v0.1.1 公测版 · MIT

宇树机器人可视化积木编程桌面软件。拖拽积木即可生成 Python 代码，一键运行对接 unitree_sdk2py，支持 Go2 四足机器人与 G1 人形机器人。

支持平台 macOS (Intel / Apple Silicon) · Linux x64 许可证 MIT License 代码仓库 GitHub 语言构成 Python 51.2% / JavaScript 26.9% / Shell 10.4% / HTML 8.0%
  • 积木编程：基于 Blockly，支持循环与条件嵌套
  • 代码生成：一键输出可读的 Python 脚本
  • 一键运行：执行生成脚本并输出到日志面板
  • 状态监控：DDS 订阅 rt/lowstate
  • 摄像头回传：实时显示机器人画面
  • 激光雷达：叠加 Go2 点云与测距标尺
  • 程序存取：XML 工程保存 / 加载 / 导出 .py
  • 网络配置：内置网卡检测与一键静态 IP
