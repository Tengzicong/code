下载

选对架构，装上就用。

浏览器会预选你当前的系统与芯片；拿不准时，参照下方系统要求手动选择即可。

选择您的操作系统

Intel 与 Apple Silicon 的安装包互不通用，请按芯片型号选择。

正在检测您的系统与芯片架构…

macOS 首次打开需要通过 Gatekeeper

本软件未做 Apple 开发者签名与公证（无开发者证书），首次打开会被系统拦截。任选一种方式即可正常运行：

  1. 右键点击应用图标 → 打开 → 在弹窗中再次点击打开（仅需一次）
  2. 系统设置 → 隐私与安全性 → 在底部提示处点击仍要打开
  3. 或在终端移除隔离属性：
xattr -dr com.apple.quarantine /Applications/RobotBlockly.app

安装步骤：双击挂载 .dmg → 将 RobotBlockly.app 拖入「应用程序」→ 弹出磁盘。

装之前，先看一眼

macOS · Intel Intel x86_64 · macOS 12 Monterey 及以上

仅适用于 Intel 芯片机型；与 Apple Silicon 版本互不通用。

macOS · Apple Silicon Apple M 系列芯片 · macOS 12 Monterey 及以上

适用于 Apple M 系列芯片；原生 arm64 安装包正在打包中。

Linux 主流发行版 · amd64

适用于主流发行版；需具备与机器人通信的有线网口。

Windows Windows 10 及以上 · x64

64 位系统；安装包正在打包中。

通用要求：与机器人处于同网段；Go2 固件 ≥ 1.1.6（MCF 模式）。

连接

让电脑和 Go2 说上话。

Go2 出厂固定 IP 为 192.168.123.161，不提供 DHCP。有线直连时，把电脑网卡通配为静态 IP 192.168.123.241/24 即可握手；软件内置网卡检测与一键配置（Linux）。

① 下载安装包

在下载中心自动识别系统，或手动选择 macOS / Linux 对应安装包。

② 网线直连

电脑有线口接 Go2，按右侧命令通配静态 IP，与机器人同网段。

③ 搭积木，点运行

生成 Python 后点击「运行」，底部日志实时反馈执行结果。

# Linux
sudo ip addr add 192.168.123.241/24 dev <网卡名>

# macOS
sudo ifconfig <网卡名> 192.168.123.241 netmask 255.255.255.0

运动控制需先调用 BalanceStand() 解锁，再发送 Move 指令；Go2 固件需 ≥ 1.1.6（MCF 模式）。
