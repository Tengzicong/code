开源软件

Robot Blockly

v0.1.1 公测版 · MIT

宇树机器人可视化积木编程桌面软件。拖拽积木即可生成 Python 代码，一键运行对接 unitree_sdk2py，支持 Go2 四足机器人与 G1 人形机器人。

当前平台 Linux amd64 许可证 MIT License 仓库 Gitee 语言构成 Python 51.2% / JavaScript 26.9% / Shell 10.4% / HTML 8.0%
  • 积木编程：基于 Blockly，支持循环与条件嵌套
  • 代码生成：一键输出可读的 Python 脚本
  • 一键运行：执行生成脚本并输出到日志面板
  • 状态监控：DDS 订阅 rt/lowstate，显示 IMU / 电池 / 电机
  • 摄像头回传：实时显示机器人画面
  • 激光雷达：叠加 Go2 点云，支持测距标尺
  • 程序存取：Blockly XML 工程保存 / 加载 / 导出 .py
  • 网络配置：内置网卡检测与一键静态 IP 配置

ERROR-CORE 小游戏平台

纯前端 · 源码公开

本站点本身。纯 HTML / CSS / JavaScript 实现的静态小游戏平台，无后端依赖，可直接部署到任意静态托管服务。

技术 HTML5 Canvas / CSS3 / 原生 JavaScript 依赖 无框架 适配 桌面与移动端响应式
  • 贪吃蛇 Snake
  • 射击游戏 Shooting
  • 打砖块 Breakout
  • 足球射门 Football
  • 画板 Drawing
  • 触屏长按连续操控适配
  • Cookie 政策与同意弹窗
  • 设备检测与移动端工具栏
